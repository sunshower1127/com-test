# 유즈케이스 1: 문서 생성 (Create Document)

## 1. 기본 플로우

```
사용자: "이력서 만들어줘"
→ LLM이 COM 코드 생성 → 실행 → 문서 완성
```

생성 자체는 단순. **문제는 그 다음.**

---

## 2. 수정 요청 시나리오

### 시나리오 A: 사용자가 안 건드림

```
사용자: "이름을 김철수로 바꿔줘"

방법 1 — 코드 기반 수정:
  이전 코드에서 "홍길동" 부분만 변경 → 재실행
  장점: 빠름, 이전 코드를 그대로 활용
  단점: 전체 문서를 처음부터 다시 생성 (서식 조절 등 시간 소요)

방법 2 — AllReplace:
  AllReplace("홍길동", "김철수")
  장점: 한 줄, 빠름
  단점: "홍길동"이 여러 곳에 있으면 전부 바뀜

방법 3 — HWPML2X 라운드트립:
  XML에서 해당 셀만 수정
  장점: 정확, 서식 보존
  단점: 무거움 (생성 직후에는 과잉)
```

**최적 전략:** 단순 텍스트 수정 → AllReplace. 구조 변경 → 코드 재실행.

### 시나리오 B: 사용자가 몰래 수정함

```
1. LLM이 이력서 생성 (코드 A로)
2. 사용자가 직접 폰트 바꾸고 내용 수정 (LLM은 모름)
3. 사용자: "이름 바꿔줘"
```

이때 각 방법의 결과:

| 방법 | 결과 |
|------|------|
| 코드 재실행 | ❌ **사용자 수정 전부 날아감** (처음부터 다시 생성) |
| AllReplace | ✅ 사용자 수정 보존, 텍스트만 바뀜 |
| HWPML2X 라운드트립 | ✅ 사용자 수정 보존 (최신 XML에서 수정) |

**핵심 문제: LLM은 사용자가 수정했는지 모른다.**

---

## 3. 해결 전략

### 원칙: "생성 직후가 아니면, 항상 현재 문서 상태를 기준으로"

```
수정 요청이 들어오면:
  1. 이전 코드가 있는가?
     → YES: 문서가 수정됐는가? (IsModified 체크)
       → 수정 안 됨: 코드 기반 수정 가능
       → 수정 됨: 코드 버리고 현재 문서 기준으로 (HWPML2X 또는 AllReplace)
     → NO: 현재 문서 기준으로

  2. 수정 범위 판단:
     → 텍스트 치환: AllReplace (가장 빠름)
     → 특정 셀 수정: HWPML2X 라운드트립
     → 구조 변경 (행 추가 등): 코드 재실행 (사용자에게 경고)
```

### IsModified 활용

```js
// LLM이 코드 실행한 직후 상태를 기록
var baseline = hwp.IsModified;  // 또는 텍스트 해시

// 수정 요청 시 체크
if (hwp.IsModified !== baseline) {
  // 사용자가 뭔가 건드림 → 코드 재실행 금지
  // HWPML2X 또는 AllReplace로 처리
}
```

## 4. 수정 방법 선택 가이드

```
수정 요청
  │
  ├─ 텍스트 치환? (A→B)
  │   └─ AllReplace ✅ (가장 안전, 사용자 수정 보존)
  │
  ├─ 특정 위치에 값 넣기?
  │   └─ HWPML2X 라운드트립 ✅
  │
  ├─ 구조 변경? (행 추가, 표 생성 등)
  │   ├─ 사용자가 안 건드림 → 코드 수정 후 재실행
  │   └─ 사용자가 건드림 → ⚠️ 사용자에게 확인
  │       "직접 수정하신 내용이 있는 것 같습니다.
  │        구조 변경 시 해당 수정이 사라질 수 있습니다.
  │        진행할까요?"
  │
  └─ 서식 변경? (볼드, 색상 등)
      └─ COM 직접 (CharShape 등)
```

## 5. 요약

| 상황 | 최적 방법 | 사용자 수정 보존 |
|------|----------|:--------------:|
| 생성 직후 텍스트 수정 | AllReplace | ✅ |
| 생성 직후 구조 변경 | 코드 재실행 | ✅ (아직 안 건드림) |
| 사용자 수정 후 텍스트 수정 | AllReplace | ✅ |
| 사용자 수정 후 구조 변경 | 확인 후 코드 재실행 | ⚠️ 경고 필요 |
| 위치 모를 때 | HWPML2X 구조 파악 → 수정 | ✅ |
