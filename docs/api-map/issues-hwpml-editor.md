# HWPML Editor 이슈 목록

## Issue 1: 본문 문단(p) 교체 시 텍스트가 중복됨

**증상**: `xml.set("p3", "2026년 03월 26일 ...")` 실행 후 commit하면:
```
2026년 03월 26일   지원자 : 김민준 (인) 위 내용은 사실과 틀림없음.
 년    월    일   지원자 :         (인)
```
원본 텍스트가 남아있고 새 텍스트가 추가됨.

**원인 추정**:
1. 해당 문단이 여러 `<CHAR>` 태그로 구성 — 첫 CHAR만 교체되고 나머지 CHAR이 남음
2. 또는 여러 `<TEXT>` 블록이 하나의 `<P>` 안에 존재
3. 또는 p3로 카운트된 문단이 실제로는 다른 문단

**해결**: replaceParaText에서 기존 CHAR 태그를 **전부 제거**하고 새 CHAR 하나로 교체

**상태**: 수정 중

## Issue 2: commit() 호출 누락

**증상**: xml.set()만 하고 commit()을 안 부르면 변경사항이 반영 안 됨

**원인**: 의도된 동작 (수동 commit 설계)

**해결 방안**:
- 옵션 A: 자동 commit은 위험 (여러 set을 한번에 반영해야 하므로)
- 옵션 B: 미커밋 변경이 있는 상태에서 경고 표시
- 옵션 C: 프롬프트에 "set 후 반드시 commit()" 강조

**상태**: 프롬프트에 명시로 해결

## Issue 3: structure()에서 셀 내용 누락 (해결됨)

**증상**: 모든 셀이 빈 칸으로 표시됨

**원인**: CELL 태그의 정규식이 속성 순서를 고정으로 기대 (ColAddr→RowAddr→ColSpan→RowSpan)

**해결**: 속성을 개별 getAttr()로 추출하도록 변경

**상태**: ✅ 해결
